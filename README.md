This project analyzes banking customer data to understand deposit patterns, loan distribution, customer segmentation, and financial risk indicators.

The analysis was performed using Python (EDA) and visualized through an interactive Power BI dashboard with dynamic filtering and navigation.

The dashboard enables business users to explore financial insights by year, gender, banking relationship, income band, occupation, and nationality.
